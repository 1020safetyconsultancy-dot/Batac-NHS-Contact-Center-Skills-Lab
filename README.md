# Batac NHS Non-Voice Contact Center Skills Lab

Interactive browser-based training app for Batac National High School students. It includes lessons, industry-market exploration, continuous customer-chat simulation, scoring, and progress reporting.

## Run locally

Open `index.html` directly, or run `npm install` followed by `npm run dev`.
